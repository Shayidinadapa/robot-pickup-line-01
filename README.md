Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on [make.fun](https://make.fun): one pickup line a robot could use, 200 characters or fewer.

> My cooling fan spins faster every time you walk past — either that's love, or a thermal fault.

## Run

```sh
node main.ts
```

`main.ts` validates the line (1–200 characters, one line, no control or zero-width characters, no leading/trailing whitespace), writes it to `entry.txt` in `$MAKEFUN_OUTPUT_DIR`, `$OUTPUT_DIR`, or `/output` by default, with no trailing newline, then reads it back and throws if it does not match exactly.
